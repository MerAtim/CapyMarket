# 🛍️ CapyMarket

**CapyMarket** es un e-commerce básico con integración de [MercadoPago](https://www.mercadopago.com.ar/) para pagos en línea. Ideal como base para proyectos de venta digital, prototipos o aprendizaje.

---

## 🚀 Características

- 🧩 Frontend simple con HTML, CSS y JS
- 🛒 Backend en Express con integración de MercadoPago
- 🔐 Seguridad mejorada con variables de entorno
- 🔄 Redirecciones personalizadas según el estado del pago
- 📦 Estructura modular para escalar fácilmente
